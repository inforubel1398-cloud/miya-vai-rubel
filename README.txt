MiYa Vai RUBEL website
======================

Files:
- index.html: website content
- style.css: design and responsive layout
- script.js: menu, scroll progress, and reveal animations

How to preview:
1. Extract the ZIP.
2. Open index.html in a browser. An internet connection is needed for the online photos and Google Fonts.

How to publish free with GitHub Pages:
1. Create or sign in to a GitHub account.
2. Create a new public repository, for example: miya-vai-rubel-website.
3. Upload index.html, style.css, and script.js to the repository root.
4. Open repository Settings -> Pages.
5. Under Build and deployment, select Deploy from a branch, choose main and /(root), then Save.
6. Wait for the published link to appear in the Pages section.
